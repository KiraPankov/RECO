# RECO — нейро-стенографист для Android

Android-приложение **локально** превращает аудиозапись разговора в структурированную расшифровку:
- определяет говорящих;
- делит речь на реплики;
- ставит временные метки начала и конца каждой реплики;
- экспортирует результат в JSON.

Все модели встроены в APK, вся обработка идёт на телефоне. Интернет не нужен, разрешения на доступ к нему у приложения нет.

| Что требуется | Как сделано |
|---|---|
| Android OS | Android 8.0+ (minSdk 26), Kotlin + Jetpack Compose |
| Импорт аудио из памяти устройства | Системный выбор файла (mp3, m4a, ogg/opus, wav, flac, amr, звук из mp4); также запись в приложении |
| Речь → текст | NVIDIA Parakeet TDT 0.6B v3 (sherpa-onnx) |
| Определение и разделение говорящих | sherpa-onnx: pyannote segmentation 3.0 находит смены говорящих, CAM++ строит «отпечаток» голоса; Silero VAD находит паузы, по которым разрезаются склеенные реплики; затем собственный второй проход уточнения |
| Локальная LLM | Qwen3-0.6B (Google LiteRT-LM) расставляет пунктуацию и заглавные буквы. Если LLM изменила хоть одно слово, её ответ отбрасывается — WER от неё вырасти не может |
| Временные метки | `start_ms` / `end_ms` для каждой реплики |
| Отображение расшифровки | Диалог с участниками и временем; воспроизведение с переходом к реплике |
| Экспорт в файл | JSON в формате задания, сохранение в выбранное пользователем место |

## Установка

1. Скачайте APK со страницы **Releases** этого репозитория (1,1 ГБ: модели внутри).
2. Откройте файл на телефоне и разрешите установку из неизвестных источников. Нужен телефон с arm64-v8a (почти все современные) или эмулятор x86_64.
3. При первом запуске модели один раз распаковываются во внутреннюю память. На главном экране в это время виден прогресс, интернет не нужен. Свободного места нужно около 2,5 ГБ.

## Использование

1. **Импорт** → выберите аудиофайл. Можно также нажать **Запись** и записать разговор. Прогресс обработки виден на карточке и в уведомлении.
2. Откройте готовую расшифровку:
   - нажатие на реплику включает воспроизведение с этого места;
   - долгое нажатие открывает правку текста или говорящего и повторную обработку фрагмента.
3. **Экспорт JSON** (вверху справа) → выберите, куда сохранить файл.

```json
{
  "transcript": [
    { "speaker_id": "speaker_1", "start_ms": 31, "end_ms": 6055, "text": "Добрый день! Давайте начнем совещание." }
  ]
}
```
