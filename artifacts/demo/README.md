▶ **Видео (1 мин 53 с):** [RECO-demo.mp4](https://github.com/KiraPankov/RECO/releases/download/v1.0.0/RECO-demo.mp4)

## Пояснения к цифрам в видео

- **RTF 1,28** — на эмуляторе Android на ПК; на реальном телефоне скорость не замеряли. Замер на ПК без эмулятора — RTF ≈ 0,23 (см. [TEST_RESULTS.md](../../docs/TEST_RESULTS.md)).
- **LLM: исправлено 0, отклонено 7.** LLM работает на устройстве, но на этой записи все 7 её ответов отброшены проверкой слов: модель попыталась изменить слова, а не только пунктуацию. Остался текст распознавателя с его пунктуацией — так WER от LLM вырасти не может. Подробнее — в [ARCHITECTURE.md](../../docs/ARCHITECTURE.md#локальная-llm-только-пунктуация-слова-не-меняются).
