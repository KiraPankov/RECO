# Демонстрация работы

▶ **Видео:** [RECO-demo.mp4](https://github.com/KiraPankov/RECO/releases/download/v1.0.0/RECO-demo.mp4)

Видео и APK приложены к релизу [v1.0.0](https://github.com/KiraPankov/RECO/releases/tag/v1.0.0): в репозиторий файлы больше 100 МБ не загрузить.

## Что показано в видео

- установка APK и первый запуск (подготовка моделей, интернет не нужен);
- импорт аудиофайла из памяти устройства и прогресс обработки, включая этап пунктуации локальной LLM;
- готовая расшифровка: участники, временные метки, воспроизведение с переходом к реплике;
- экспорт результата в JSON-файл.

## Пример экспортированного JSON

Содержимое экспорта в формате задания — например, [`artifacts/test-results/output/clean.json`](../test-results/output/clean.json) (результат обработки тестового диалога):

```json
{
  "transcript": [
    { "speaker_id": "speaker_1", "start_ms": 31, "end_ms": 6055, "text": "Добрый день! Давайте начнем совещание. Сегодня обсуждаем запуск нового приложения." }
  ]
}
```

## Что есть в приложении, но не вошло в видео

- **Правка реплики и повторная обработка фрагмента:** долгое нажатие на реплику открывает правку текста и говорящего и кнопку повторного распознавания фрагмента.
- **Итоги работы LLM:** в окне «Сведения» вверху экрана расшифровки — плитки «LLM: пунктуация исправлена» и «LLM: ответов отклонено»; реплики, где LLM изменила пунктуацию, помечены меткой «LLM». Parakeet уже сам ставит пунктуацию, поэтому на чистой речи LLM часто ничего не меняет и счётчики показывают 0.
