# Демонстрация работы

▶ **Видео:** [RECO-demo.mp4](https://github.com/KiraPankov/RECO/releases/download/v1.0.0/RECO-demo.mp4)

Видео и APK приложены к релизу [v1.0.0](https://github.com/KiraPankov/RECO/releases/tag/v1.0.0): в репозиторий файлы больше 100 МБ не загрузить.

## Что показано

- установка APK и первый запуск (карточка «Подготовка моделей», интернет выключен);
- импорт аудиофайла из памяти устройства и прогресс обработки;
- готовая расшифровка: участники, временные метки, воспроизведение с переходом к реплике;
- правка реплики и повторная обработка фрагмента;
- работа локальной LLM: метки «LLM» у реплик и строка «LLM: пунктуация исправлена в …, отклонено …» в заголовке;
- экспорт JSON в файл и его содержимое.
