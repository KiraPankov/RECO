# Материалы демонстрации

Добавьте сюда видео или ссылку на него. В видео стоит показать:

- установку APK и первый запуск (карточка «Подготовка моделей», интернет выключен);
- импорт аудиофайла из памяти устройства и прогресс обработки;
- готовую расшифровку: участники, временные метки, воспроизведение с переходом к реплике;
- правку реплики и повторную обработку фрагмента;
- работу локальной LLM: метки «LLM» у реплик и строку «LLM: пунктуация исправлена в …, отклонено …» в заголовке;
- экспорт JSON в файл и его содержимое.
